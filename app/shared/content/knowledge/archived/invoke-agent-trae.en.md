# Invoke Ethan in TRAE (archived note)

Test seed for **`internal_page_folder`** subfolder with **`open`: `same_tab`**.

| Topic | Detail |
| --- | --- |
| Agent file | `~/.trae/agents/ethan.md` |
| Setup | Settings → Beta → turn Subagents on. |
| Start Ethan | Type `@`. The built-in agent calls Ethan when your message matches `description`. `/ethan` does not work. |
| Invoke again | Separate thread. The parent chat is not guaranteed to stay on Ethan. |

See the main **How to invoke custom agents** article for TRAE CN and other IDEs.
