# 在 TRAE 中召唤 Ethan（归档说明）

**`internal_page_folder`** 子文件夹测试种子，**`open`** 为 **`same_tab`**。

| 项目 | 说明 |
| --- | --- |
| 智能体文件 | `~/.trae/agents/ethan.md` |
| 设置 | 设置 → Beta → 开启 Subagents。 |
| 启动 Ethan | 输入 `@`。内置 agent 在消息匹配 `description` 时调用 Ethan。`/ethan` 无效。 |
| 再次唤起 | 独立会话。主对话不保证仍是 Ethan。 |

TRAE CN 及其他 IDE 见主目录 **如何召唤自建智能体** 一文。
