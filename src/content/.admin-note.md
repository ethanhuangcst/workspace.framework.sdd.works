# Notes to the admin

Read this note before you update framework.sdd.works

## **How to update framework.sdd.works artifacts**

- Copy the newest framework artifacts to local framework workspace folder
- Sync with Git repo (default: "[https://github.com/ethanhuangcst/framework.sdd.works.git](https://github.com/ethanhuangcst/framework.sdd.works.git)")
- sdd.works web app will auto sync every 30 minutes, or manual sync on Admin portal - Framework - Sync with git repository

### Include in this repository

#### Repo root


| #   | Path                               | Purpose                                                                              |
| --- | ---------------------------------- | ------------------------------------------------------------------------------------ |
| 1   | `lite-pack.allowlist.json`         | Lite HTTP install allow-list at pack root (ADR-107).                                 |
| 2   | `.pack-repo-scope-readme.md`       | This scope readme for pack maintainers.                                              |
| 3   | `.sdd-installed.example.json`      | Field example only. `pack_complete` is false. Not a client receipt.                  |
| 4   | `.sdd-lite-installed.example.json` | Field example for lite receipt shape. Not written on `{client_root}` from this repo. |




#### Pack install tree


| #   | Path                       | Purpose                                                             |

| 3   | `rules/`                   | Rule files copied on full MCP install and listed for lite install.  |

| 6   | `templates/HanS/`          | Simplified Chinese process artifact templates.                      |

#### Portal content (web app)


| #   | Path                      | Purpose                                                 |
| --- | ------------------------- | ------------------------------------------------------- |
| 1   | `content/features/`       | Features tab markdown (ADR-071).                        |
| 2   | `content/scrum-in-sdd/`   | Scrum in SDD tab markdown.                              |

### Exclude from this repository


| #   | Path or pattern                             | Purpose                                                                                        |
| --- | ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 1   | Client install ledgers                      | Real `{client_root}/.sdd-installed.json` or `.sdd-lite-installed.json` from a machine install. |
| 2   | `pack_complete: true` in any committed file | Receipts are written on the client after install, not shipped in Git.                          |
| 3   | Product app tree                            | `src/`, `specs/`, and other framework.sdd.works product repo code.                             |
| 4   | Live secrets                                | Real API keys in `.secrets`.                                                                   |
| 5   | OS junk                                     | `.DS_Store` and similar.                                                                       |


Before push: `npm run check:pack-seeds` in the product repo.
