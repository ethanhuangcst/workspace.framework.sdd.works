# 在 TRAE 中叫出 Ethan（封存說明）

**`internal_page_folder`** 子資料夾測試種子，**`open`** 為 **`same_tab`**。

| 項目 | 說明 |
| --- | --- |
| 智能體檔 | `~/.trae/agents/ethan.md` |
| 設定 | 設定 → Beta → 開啟 Subagents。 |
| 啟動 Ethan | 輸入 `@`。內建 agent 在訊息符合 `description` 時叫 Ethan。`/ethan` 無效。 |
| 再叫一次 | 獨立對話。主對話不保證仍是 Ethan。 |

TRAE CN 及其他 IDE 見主目錄 **如何叫出自訂智能體** 一文。
