MCP instructions

How to call framework.sdd.works. The server id is framework.sdd.works. Callers send a bearer token. Key values come from sdd_get_key.

1. Tools 2. stdio 3. Streamable HTTP

1. Tools

HTTP and stdio share the same core. Descriptions include failure modes.

Tool Channel Description
sdd_list_versions stdio and HTTP List package versions and inventory. Read-only.
sdd_get_key stdio and HTTP Return plaintext key_value for key_name. Auth required.
sdd_install_framework stdio (local writes) Install skills, rules, and other folders on the developer machine.
sdd_update_framework stdio (local writes) Update an existing install. Same version is idempotent.

2. stdio

Local desktop clients (Cursor, Claude Code, VS Code) run the stdio binary. Install and update write the caller’s skill and rule paths.

3. Streamable HTTP

Remote clients use https://framework.sdd.works/mcp with Authorization: Bearer. HTTP install does not write the server disk.
