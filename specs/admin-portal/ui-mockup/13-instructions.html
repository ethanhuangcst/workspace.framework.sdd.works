Install framework.sdd.works to your AI tools

SKILLS.RULES.AGENTS.TEMPLATES

Once MCP is connected, type to AI:

Install SDD.works Framework

or, directly call MCP tool by giving the command:

sdd_install_framework

Manual setup

Prefer not to use the setup prompt? Add this MCP entry. Leave every other server unchanged.

mcp.json 
{
  "mcpServers": {
    "framework.sdd.works": {
      "command": "${userHome}/.sdd/sdd-mcp",
      "env": {
        "SDD_SERVER_URL": "https://framework.sdd.works"
      }
    }
  }
}
