# framework.sdd.works pack seed Git repo scope readme

**How to update framework.sdd.works**

- Copy the newest framework artifacts to local framework workspace folder
- Sync with Git repo (default: "[https://github.com/ethanhuangcst/framework.sdd.works.git](https://github.com/ethanhuangcst/framework.sdd.works.git)")
- sdd.works web app will auto sync every 30 minutes, or manual sync on Admin portal - Framework - Sync with git repository

## Exclude from this repository


| #   | Path or pattern                             | Purpose                                                                                        |
| --- | ------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| 1   | Client install ledgers                      | Real `{client_root}/.sdd-installed.json` or `.sdd-lite-installed.json` from a machine install. |
| 2   | `pack_complete: true` in any committed file | Receipts are written on the client after install, not shipped in Git.                          |
| 3   | Product app tree                            | `src/`, `specs/`, and other framework.sdd.works product repo code.                             |
| 4   | Live secrets                                | Real API keys in `.secrets`.                                                                   |
| 5   | OS junk                                     | `.DS_Store` and similar.                                                                       |


Before push: `npm run check:pack-seeds` in the product repo.
