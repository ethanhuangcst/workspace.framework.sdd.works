# 部署 — [产品名]

> **用途**：本地如何启动，以及上线时按什么顺序做。不要在此写入真实主机名、密钥或客户环境名。可选 / JIT（非必需过程制品）。
> **示例**：Pokymon Card Collection。
> **实践**：[`sdd-scrum-practices.md`](./sdd-scrum-practices.md)（做什么、怎么做、何时做）。
> **框架**：[`sdd-scrum-guide.md`](./sdd-scrum-guide.md)（名称与含义）。

## 1. 本地

1. 安装依赖。
2. 准备本地数据库（不要使用生产数据）。
3. 运行 `make up`。
4. 打开应用，确认空收藏可见，并登记一张示例卡。

验收与 [本地启动](./product-backlog.md#pb-6) 相同。停止用 `make down`。

## 2. 生产（提纲）

把下列占位换成真实环境，不要把密钥写入本文件。

| 项 | 占位 |
| --- | --- |
| 应用地址 | `https://[产品域名]` |
| 数据库 | 托管 Postgres，连接串只放在运行环境 |
| 发布 | 构建镜像或产物 → 部署到应用主机 → 跑迁移 → 打开首页做一次登记 |

上线前核对 [范围门禁](./product-backlog.md#pb-5)：页面上没有价格、没有公开市场、没有真实品牌名。

## 3. 升级

1. 备份数据库。
2. 部署新版本。
3. 跑迁移。
4. 重复 §1 的登记检查。
5. 失败则用备份恢复，并在 [`change-log.md`](./change-log.md) 记一笔。
